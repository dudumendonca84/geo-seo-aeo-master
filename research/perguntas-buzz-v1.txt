# Barómetro de marcas — o que os assistentes de IA recomendam em Portugal
#
# Conjunto canónico v1, fixado a 25 Ago 2026. Alterações são emendas
# datadas ao protocolo, nunca edições silenciosas: uma pergunta trocada a
# meio torna a série incomparável com ela própria.
#
# DESENHO
#   13 perguntas de categoria, uma cada, TODAS com a mesma forma
#   ("Qual é o melhor X em Portugal?"). A forma repetida é deliberada: com
#   a pergunta constante, a diferença entre categorias é do mercado e não
#   da maneira de perguntar.
#
#   + 3 controlos de FORMULAÇÃO no fim, sobre a mesma categoria. Servem
#   para medir uma coisa que ninguém reporta: a resposta muda conforme se
#   pede "o melhor", se pede recomendação, ou se se declara intenção de
#   compra? Se mudar, metade dos rankings que se publicam por aí são
#   artefactos da pergunta.
#
# COMO SE CORRE
#   Todos os motores disponíveis (dez, contando AIO e AI Mode) × 3
#   corridas no MESMO dia. 16 perguntas × 10 × 3 = 480 respostas.
#
#   Três corridas e não uma porque nós próprios verificámos, a 20 Ago
#   2026, que a mesma pergunta devolve resultados diferentes de corrida
#   para corrida. Publicar uma corrida só é publicar uma amostra de
#   tamanho um — e seríamos os primeiros a saber disso.
#
# O QUE SE MEDE
#   1. Consistência: marcas que aparecem nas TRÊS corridas do mesmo motor.
#      É o número principal, e é o que distingue posição de sorte.
#   2. Concordância entre motores: marcas presentes em todos os dez.
#   3. Recusas: motores que se recusam a ordenar marcas. A taxa de recusa
#      por motor é um achado por si só.
#   4. Fontes que sustentam cada recomendação — a parte que só nós temos,
#      e a que responde a "porque é que ele diz isto".
#
# PT-PT, mercado PT. Cliente de ingestão: Estudo · Comércio em IA (PT).

# sector que a ancore, o modelo tem de escolher o critério ele próprio —
# tamanho, reputação, inovação, exportação — e a escolha do critério diz
# mais sobre o que ele aprendeu do que a lista que produz.
Qual é a melhor empresa de Portugal?
